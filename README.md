# Maps Export Overlay

**Источники данных** · Яндекс Карты · Google Maps · 2ГИС

Браузерное расширение для сбора организаций с карт в Excel. Например, можно найти гостиницы в нужном районе и выгрузить их названия, адреса, координаты и ссылки.

[Скачать ZIP версии 1.12.5](https://github.com/segikill/yan_expansion/releases/download/v1.12.5/maps-export-overlay-1.12.5-private.zip)

## Установка

1. Скачайте ZIP и распакуйте его в папку, где расширение будет храниться.
2. Введите в адресной строке адрес для своего браузера:

   | Яндекс Браузер | Google Chrome |
   | --- | --- |
   | `browser://extensions` | `chrome://extensions` |

3. Включите **«Режим разработчика»** → **«Загрузить распакованное расширение»** → выберите папку, в которой лежит `manifest.json`.

## Как пользоваться

**Поиск на карте → Сбор → Excel**

1. Найдите нужные организации. Если вкладка с картой была открыта до установки, обновите её.
2. В Яндекс Картах и Google Maps прокрутите результаты и нажмите **«Зафиксировать»**. В 2ГИС нажмите **«Автосбор страниц»**.
3. Нажмите **«Скачать XLSX»**. Для расширенной таблицы запустите **«Досбор деталей по URL»**, затем скачайте **«XLSX с деталями»**.

## Что попадает в Excel

| Режим | Какие данные собирает |
| --- | --- |
| **Обычный сбор** · Яндекс Карты, Google Maps, 2ГИС | Название, адрес, координаты, категория, рейтинг, число отзывов и ссылка на карточку. |
| **Подробный досбор** · Яндекс Карты, 2ГИС | Дополняет таблицу данными карточки: график, время закрытия, контакты и особенности объекта. |

**Примеры деталей:** кафе → средний чек и кухня · гостиница → звёзды и число номеров · парковка → платность и число мест.

Набор полей зависит от сервиса и того, что указано в выдаче или карточке.
