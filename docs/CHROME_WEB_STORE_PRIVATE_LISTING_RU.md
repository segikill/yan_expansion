# Закрытая публикация Maps Export в Chrome Web Store

Пакет: `maps-export-overlay-1.12.4-private.zip`

Дата подготовки: 21 августа 2026 года.

## 1. Рекомендуемый режим распространения

В разделе `Distribution` выбрать:

- Visibility: `Private`;
- Regions: только необходимые страны либо `All regions`, если тестировщики находятся в разных странах;
- доступ: Google-аккаунты Trusted testers или принадлежащая разработчику Google Group.

Каждый адрес тестировщика должен быть связан с Google Account. `Unlisted` не подходит для действительно закрытой публикации: расширение сможет установить любой человек, получивший ссылку. Режимы Public, Unlisted и Private проходят одинаковую проверку Chrome Web Store.

## 2. Store Listing

### Название

`Maps Export Overlay: Yandex, Google, 2GIS`

### Краткое описание

`Сбор карточек организаций с карт, локальный досбор по URL и экспорт результатов в XLSX.`

### Категория и язык

- Category: `Productivity`;
- Language: `Russian`.

### Подробное описание

```text
Maps Export помогает собирать публичные сведения о карточках организаций с Яндекс Карт, Google Maps и 2ГИС и сохранять результат в XLSX.

Работа разделена на два этапа:
1. Базовый сбор карточек из открытой пользователем выдачи карт.
2. Подробный досбор по сохранённым URL в 1–4 фоновых вкладках.

Расширение собирает доступные сведения об организациях: названия, адреса, категории, рейтинги, отзывы, координаты, графики работы, контакты и категорийные особенности. Для 2ГИС предусмотрен быстрый постраничный автосбор без изменения масштаба карты и отдельный подробный сбор вкладки «Инфо».

Пользователь управляет запуском, паузой, остановкой, повтором ошибок, сбросом и экспортом. При появлении CAPTCHA или ограничения сервиса очередь останавливается и сохраняет прогресс; расширение не обходит защитные механизмы сайтов.

Сессия, настройки и результаты хранятся локально в браузере. Расширение не отправляет собранные данные разработчику, не использует внешнюю аналитику и не показывает рекламу.
```

## 3. Privacy practices

### Single purpose

```text
Сбор, локальное сохранение, дополнение по URL и экспорт в XLSX публичных сведений о карточках организаций из поддерживаемых картографических сервисов.
```

### Обоснование разрешений

`scripting`

```text
Используется только после явного нажатия пользователя в popup, чтобы восстановить интерфейс расширения на уже открытой поддерживаемой странице карты, если content script ещё не подключён.
```

`storage`

```text
Нужно для локального хранения базовой сессии, настроек, очереди подробного досбора и результатов до экспорта или явного сброса пользователем.
```

`unlimitedStorage`

```text
Нужно для предотвращения потери больших пользовательских сессий с тысячами карточек и подробными категорийными атрибутами при превышении стандартной локальной квоты. Данные не синхронизируются и не передаются разработчику.
```

`alarms`

```text
Используется как локальный watchdog фоновой очереди: восстанавливает обработку после выгрузки service worker, контролирует зависшие задачи и не запускает сбор без созданного пользователем задания.
```

Host permissions

```text
Доступ ограничен страницами Яндекс Карт, Google Maps и 2ГИС. Он нужен для чтения видимых результатов и открытых в фоновых вкладках публичных карточек организаций. Расширение не работает на остальных сайтах.
```

### Remote code

Выбрать: `No, I am not using remote code`.

SheetJS поставляется локально в пакете как `xlsx.full.min.js`. Внешние скрипты, `eval` и динамическая загрузка исполняемого кода не используются.

### Категории обрабатываемых данных

Отметить:

- `Website content` — текст и структурированные публичные сведения карточек;
- `Web history / browsing activity` — URL карточек на поддерживаемых доменах, сохраняемые в локальной сессии.

Не отмечать местоположение пользователя: координаты относятся к организациям. Не отмечать authentication, financial, health, personal communications и user files.

Во всех сертификациях указать:

- данные используются только для единой функции расширения;
- данные не продаются и не используются для рекламы или кредитования;
- данные не передаются третьим лицам;
- человек не читает пользовательские данные;
- обработка соответствует Limited Use.

Явное раскрытие размещено непосредственно в popup, в инструкции и на встроенной странице `privacy.html` до запуска пользовательских действий.

## 4. Test instructions для ревьюера

```text
Учетная запись и платные функции не требуются.

1. Установите расширение и откройте https://yandex.ru/maps/ либо https://2gis.ru/.
2. Выполните поиск организаций, например «Гостиницы».
3. Откройте popup расширения и нажмите «Открыть панель на карте».
4. На Яндекс Картах нажмите «Зафиксировать». На 2ГИС нажмите «Автосбор страниц» и при необходимости остановите его повторным нажатием.
5. Нажмите «Скачать XLSX» — файл создаётся локально и содержит лист objects.
6. Нажмите «Досбор деталей по URL». Страница управления откроется справа от вкладки карты.
7. Выберите источник, одну рабочую вкладку и запустите очередь. Фоновые вкладки создаются только для карточек из локальной сессии и закрываются после выполнения.
8. Проверьте паузу, остановку и «Сбросить досбор».

Расширение не передаёт результаты на внешний сервер. При CAPTCHA или ограничении сервиса очередь останавливается; обход защиты не выполняется.
```

## 5. Загрузка и отправка

1. Зарегистрировать аккаунт Chrome Web Store Developer и оплатить единовременный регистрационный взнос.
2. В Developer Dashboard выбрать `Add new item`.
3. Загрузить `maps-export-overlay-1.12.4-private.zip`.
4. Заполнить Store Listing, Privacy practices и Test instructions текстами выше.
5. В Distribution выбрать `Private` и добавить тестировщиков.
6. При отправке на проверку включить deferred publishing, если требуется сначала получить одобрение и вручную решить момент публикации.
7. После одобрения проверить установку под аккаунтом доверенного тестировщика.
