# Подготовка Maps Export Overlay к Chrome Web Store

Актуально для версии 1.12.3 от 21 августа 2026 года.

## Единая цель расширения

Сбор, локальное сохранение, дополнение по URL и экспорт в XLSX публичных сведений о карточках организаций из поддерживаемых картографических сервисов.

Эту формулировку следует использовать в поле `Single purpose` и согласовать с описанием карточки магазина.

## Обоснование разрешений

- `scripting` — резервное внедрение интерфейса на уже открытой поддерживаемой странице после явного действия пользователя в popup;
- `storage` — локальное хранение сессии, очереди и результатов досбора;
- `unlimitedStorage` — предотвращение потери больших локальных наборов организаций при превышении стандартной квоты;
- `alarms` — восстановление и контроль фоновой очереди после выгрузки service worker;
- доменные разрешения — чтение карточек только на Яндекс Картах, Google Maps и 2ГИС.

`activeTab` и `tabs` удалены как избыточные. Доступ `web_accessible_resources` ограничен только сервисами, где используются внедряемые перехватчики сетевых ответов. Неиспользуемые разрешения к API 2ГИС удалены.

## Декларация данных в Privacy practices

Следует раскрыть обработку:

- Website content — содержимое карточек и результатов поиска;
- Web history / browsing activity — URL карточек на поддерживаемых доменах, поскольку они сохраняются в сессии;
- User activity — только если форма кабинета Chrome относит действия запуска и экспорта к этой категории.

Не следует отмечать геолокацию пользователя: координаты в выгрузке относятся к организациям. Также расширение не собирает аутентификационные, платёжные, медицинские данные и личные сообщения.

Цель обработки — только основная пользовательская функция. Данные не продаются, не используются для рекламы и не передаются разработчику или внешней аналитике. Политика конфиденциальности находится в `PRIVACY.md`; перед публикацией ей нужен публичный HTTPS-адрес, например GitHub Pages.

## Техническая проверка пакета

- `manifest.json` находится в корне ZIP;
- используется Manifest V3 и только `background.service_worker`;
- номер версии выше опубликованной;
- отсутствуют удалённо загружаемый JavaScript и `eval`;
- в ZIP нет `.git`, тестов, отчётов и пользовательских XLSX-файлов;
- SheetJS поставляется локально; к релизу нужно добавить его лицензию и ссылку на исходный дистрибутив версии 0.18.5;
- проверены установка в чистом профиле, popup, базовый сбор, досбор, пауза, восстановление и экспорт.

## Материалы карточки магазина

- название и краткое описание, соответствующие единой цели;
- подробное описание без обещаний обхода CAPTCHA или ограничений сервисов;
- иконка 128×128;
- минимум один снимок 1280×800 или 640×400;
- публичная политика конфиденциальности;
- рабочий адрес поддержки;
- инструкция для ревьюера с тестовым сценарием;
- категория и страны распространения;
- первоначально рекомендуется видимость `Unlisted` для закрытого тестирования.

## Рекомендуемый текст для ревьюера

Расширение начинает сбор только после действия пользователя. Оно работает исключительно на перечисленных доменах картографических сервисов, сохраняет результаты локально и экспортирует их в XLSX. Фоновые вкладки создаются только после запуска досбора и закрываются после завершения. При CAPTCHA или ограничении сервиса очередь останавливается; расширение не пытается обходить защиту.
